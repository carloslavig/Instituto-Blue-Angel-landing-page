# 💙 Instituto Blue Angel's — Website

Projeto de desenvolvimento de uma landing page institucional para o **Instituto Blue Angel's**, uma organização dedicada ao atendimento terapêutico multidisciplinar de crianças atípicas, com foco no Transtorno do Espectro Autista (TEA), localizada em **Xerém, Duque de Caxias – RJ**.

---

## 🎯 Objetivo

Criar uma plataforma digital que:

- Apresente o instituto de forma clara e acolhedora
- Divulgue serviços e especialidades
- Conecte famílias ao atendimento
- Incentive doações
- Fortaleça a presença digital da instituição

---

## 🧩 Funcionalidades

- 📌 Sobre o Instituto
- 🧠 Serviços / Especialidades
- 👩‍⚕️ Equipe multidisciplinar
- 📸 Galeria de eventos
- 📍 Contato e localização
- 💰 Área de doações
- 📱 Design responsivo (mobile-first)

---

## 🎨 Identidade Visual

- Paleta baseada em **azul bebê / tons pastel**
- Tipografia: **Playfair Display** (títulos) + **DM Sans** (corpo)
- Foco em transmitir:
  - Acolhimento
  - Confiança
  - Leveza
  - Profissionalismo

---

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis CSS, Grid, Flexbox, animações)
- JavaScript (ES6+, Intersection Observer, Fetch API)

> Projeto desenvolvido em HTML/CSS/JS puro — sem dependências ou frameworks. Basta um navegador para rodar.

## 🚀 Como rodar o projeto

Por ser um projeto estático, não precisa de instalação. Basta abrir o arquivo no navegador:

```bash
# Clonar repositório
git clone https://github.com/seu-usuario/blue-angels.git

# Entrar na pasta
cd blue-angels

# Abrir no navegador (duplo clique no arquivo ou via terminal)
open index.html       # macOS
start index.html      # Windows
xdg-open index.html   # Linux
```

> Para desenvolvimento com live reload, recomenda-se a extensão **Live Server** do VS Code.

## ✅ Personalização antes de publicar

Abra o `index.html` e substitua os campos marcados com `⚠️`:

| Campo | Onde encontrar |
|---|---|
| Endereço real | Seção Contato |
| Telefone / WhatsApp | Seção Contato + `js/main.js` |
| E-mail de contato | Seção Contato + Footer |
| Chave Pix | Seção Doações |
| CNPJ | Seção Doações |
| Links Instagram / Facebook | Footer |
| Embed do Google Maps | Seção Contato |
| Fotos da equipe | Seção Equipe |
| Fotos da galeria | Seção Galeria |
