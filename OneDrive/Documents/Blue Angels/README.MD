💙 Instituto Blue Angel’s — Website

Projeto de desenvolvimento de uma landing page institucional (web app) para o Instituto Blue Angel’s, uma organização dedicada ao atendimento terapêutico multidisciplinar de crianças atípicas, com foco no Transtorno do Espectro Autista (TEA).

🎯 Objetivo

Criar uma plataforma digital que:

Apresente o instituto de forma clara e acolhedora
Divulgue serviços e especialidades
Conecte famílias ao atendimento
Incentive doações
Fortaleça a presença digital da instituição
